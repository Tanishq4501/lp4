## 1. What the PS asks (in plain words)
Classify hand-sign letters with a CNN: load, define the architecture, train, evaluate and plot.

## 2. Dataset
- Sign-Language MNIST: 27,455 train and 7,172 test images, 28x28 grey; labels 0-24 (9 missing), so the output layer needs 25 units.
- Files: `sign_mnist_train.csv`, `sign_mnist_test.csv`.

## 3. Notebook walkthrough: every cell, and why

### Cell 0: imports
```python
import tensorflow as tf
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.metrics import classification_report
```
**Why:** `tensorflow` is imported first (on this machine importing numpy or pandas before TensorFlow can crash the TensorFlow DLL). `classification_report` gives precision, recall and F1 per class; `matplotlib` draws the curves and the example image.

### Cell 1: alias for the layers module
```python
L = tf.keras.layers
```
**Why:** `L = tf.keras.layers` is only a short name so each layer is written `L.Dense(...)` instead of `tf.keras.layers.Dense(...)`.

### Cell 2: load the data
```python
tr = pd.read_csv("sign_mnist_train.csv")
te = pd.read_csv("sign_mnist_test.csv")
Xtr,ytr = tr.drop(columns="label").values.reshape(-1,28,28,1) / 255, tr.label.values
Xte,yte = te.drop(columns="label").values.reshape(-1,28,28,1) / 255, te.label.values
```
**Why:** Same CSV layout as MNIST; keep the `(28,28,1)` shape for the convolution layers and scale by 255.

**Why not the alternative:** Not `to_categorical` (one-hot labels): the sparse loss accepts the integer labels directly, so no conversion is needed. Not skipping `/ 255`: unscaled pixels (0-255) make training slow and unstable.

### Cell 3: define the model (CNN, 25 outputs)
```python
model = tf.keras.Sequential([L.Conv2D(32, 3, activation="relu"), L.MaxPooling2D(), L.Conv2D(64, 3, activation="relu"), L.MaxPooling2D(),
                             L.Flatten(), L.Dense(128, activation="relu"), L.Dense(25, activation="softmax")])
model.summary()
```
**Why:** Two `Conv2D` layers (32 then 64 filters of 3x3, ReLU) find local patterns; each `MaxPooling2D` halves the size; `Flatten` + `Dense(128)` combines the patterns; the last `Dense` with `softmax` gives class probabilities. **`Dense(25)`** because the biggest label is 24. Parameters: 320 + 18,496 + 204,928 + 3,225 = **226,969**.

**Why not the alternative:** Not an FNN: it ignores where pixels are and has far more parameters for images. Not `padding="same"` or more layers: the simple version already works and is easy to explain and count. Not `Dense(10)`: label 24 would be out of range.

### Cell 4: compile and train
```python
model.compile(optimizer="adam", loss="sparse_categorical_crossentropy", metrics=["accuracy"])
h = model.fit(Xtr, ytr, epochs=10, batch_size=128, validation_data=(Xte, yte))
```
**Why:** Adam, sparse categorical cross-entropy, 10 epochs, batch 128 (215 iterations per epoch).

**Why not the alternative:** Not more epochs: validation loss is lowest at epoch 5 (0.386) and then rises (0.471 at epoch 10) while training accuracy reaches 100 %: the model memorises.

### Cell 5: evaluate
```python
print(model.evaluate(Xte, yte))                                  
print(classification_report(yte, model.predict(Xte).argmax(1)))
```
**Why:** `model.evaluate` returns `[test loss, test accuracy]`. `model.predict(Xte)` gives one probability per class and `.argmax(1)` picks the most probable class; `classification_report` then shows precision, recall and F1 per class so you can see which classes are weak.

**Why not the alternative:** Not accuracy alone: it hides which classes fail (letters N, R, Q and T are the weakest).

### Cell 6: training curves
```python
pd.DataFrame(h.history).plot(); 
plt.show()
```
**Why:** `pd.DataFrame(h.history).plot()` draws loss and accuracy for training and validation in one line. Both curves falling together is healthy; training much better than validation means over-fitting.

**Why not the alternative:** Not a separate plot call for each curve: the DataFrame draws all four lines at once.

### Cell 7: one example
```python
#one example
names = [chr(65+k) for k in range(25)]                         # label 0 = A ... 24 = Y
i = 0                                                          # any test image
p = model.predict(Xte[i:i+1])[0]                               # one probability per class
plt.imshow(Xte[i].squeeze(), cmap="gray"); plt.title(f"true {names[yte[i]]} | predicted {names[p.argmax()]} ({p.max():.0%})")
plt.show()
```
**Why:** Shows what a single prediction looks like: the model returns one probability per class, `argmax` gives the label and the title shows the confidence. It makes the idea concrete in the viva (an image goes in, probabilities come out).

**Why not the alternative:** Not only the aggregate accuracy: one visible example is easier to explain. 

## 4. Terminology used in this notebook

| Term | Meaning |
|---|---|
| **Conv2D** | A layer of small filters (for example 3x3) that slide over an image and detect local patterns. |
| **Filter / kernel** | The small weight window of a convolution layer. `Conv2D(32, 3)` learns 32 filters of size 3x3. |
| **MaxPooling** | Keeps the maximum of each block (2x2): halves width and height, reduces computation, adds small shift invariance. |
| **Flatten** | Turns a 2-D or 3-D feature map into one long vector so Dense layers can use it. |
| **Dense layer** | A fully connected layer: every input connects to every unit. Parameters = `inputs * units + units`. |
| **ReLU** | `max(0, x)`. Cheap hidden-layer activation that does not saturate for positive values. |
| **Softmax** | Output activation that turns scores into probabilities that sum to 1 (one per class). |
| **Adam** | An optimiser that keeps running averages of the gradient and its square, so every weight gets its own adaptive step. Default learning rate 1e-3. |
| **Over-fitting** | The model memorises the training data and does worse on new data: training score keeps rising, validation score stalls. |
| **Dropout** | Randomly switches off a fraction of units during training only, so the network cannot depend on single units (regularisation). |
| **Accuracy** | Correct predictions divided by all predictions. Misleading when classes are imbalanced. |
| **Precision** | Of everything flagged positive, the fraction that really is positive: TP / (TP + FP). |
| **Recall** | Of all real positives, the fraction found: TP / (TP + FN). |
| **F1 score** | Harmonic mean of precision and recall: 2PR / (P + R). |
| **Support** | How many true samples of each class are in the test data. |

## 5. Theory you must be able to explain

**CNN vs FNN on the same data.** 89.3 % (2C) against 72.1 % (1E): convolution and pooling keep spatial structure of the hand shape.

**Over-fitting.** Training accuracy is about 100 % from epoch 7, while validation accuracy stays around 89 % and validation loss rises after epoch 5. Fixes: Dropout, data augmentation (small shifts and rotations), early stopping.

**Why the test score is below the training score.** The model memorises the training signs; the test signs differ.

**Weak letters.** N (recall 0.52), R (F1 0.66) and Q (0.75) look like other letters (M, V, P).

## 6. Why we did this, and why not that

| Decision | Why we did it | Why not the alternative |
|---|---|---|
| CNN | Hand shape is a spatial pattern | FNN overfits more and reaches only 72 % (1E) |
| `Dense(25)` | Labels go up to 24 | 10 would crash |
| Adam, 10 epochs | Fast; validation peaks by epoch 5-9 | Longer training only widens the gap |
| No Dropout in the baseline | Keeps the model simple | Adding Dropout is the first improvement |
| Report per-letter scores | Shows N, R, Q as the weak letters | Not only accuracy |

## 7. Your result and how to read it

**Test accuracy 89.26 %**, test loss 0.4712; training accuracy 100 % so the model **over-fits** (validation loss rose after epoch 5). Best letters C and L (F1 1.00); weakest **N (F1 0.68, recall 0.52)**, R (0.66), Q (0.75), T (0.77).

Say it as: *"The CNN reaches 89 % on unseen signs, 17 points above the FNN, but it memorises the training set (100 %); Dropout or early stopping would improve generalisation."*
