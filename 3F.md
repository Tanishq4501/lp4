# PS 3F: Anomaly detection with a convolutional autoencoder on Sign-MNIST (held-out letter)

> Notebook: `3F.ipynb` | Template: B (normal-only autoencoder, Conv2D) | Wider theory: [Viva_Theory.md](Viva_Theory.md) sections 1 and 4

## 1. What the PS asks (in plain words)
Train a convolutional autoencoder on images of most letters and use it to detect the letter it has never seen: **letter Y (label 24) is the anomaly**.

## 2. Dataset
- Sign-Language MNIST (28x28 grey images): `sign_mnist_train.csv` 27,455 rows, `sign_mnist_test.csv` 7,172 rows.
- Training uses all letters **except label 24** (26,337 images). The test set has all letters: 332 Y images are the anomalies (4.6 %).
- Label 24 is Y; label 9 (J) does not exist, so do not use 9 as the anomaly.

## 3. Notebook walkthrough: every cell, and why

### Cell 0: imports
```python
import tensorflow as tf
from tensorflow import keras
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler, MinMaxScaler
from sklearn.metrics import classification_report, confusion_matrix, roc_auc_score
```
**Why:** `tensorflow` first (DLL safety on this machine). `train_test_split` splits the data, `StandardScaler` / `MinMaxScaler` scale features, `classification_report`, `confusion_matrix` and `roc_auc_score` evaluate the detector (never plain accuracy), `matplotlib` draws the histogram and curves.

### Cell 1: dataset
```python
#dataset
layers = tf.keras.layers
keras.utils.set_random_seed(42)
tr = pd.read_csv("sign_mnist_train.csv")
te = pd.read_csv("sign_mnist_test.csv")
```
**Why:** Reads the two CSV files (`tr`, `te`). `set_random_seed(42)` makes training repeatable.

### Cell 2: split and scale
```python
#split
to_img = lambda d: d.drop(columns="label").values.astype("float32").reshape(-1,28,28,1) / 255.0
Xtrall, labtr = to_img(tr), tr["label"].values
Xtes, labte = to_img(te), te["label"].values
Xtrn = Xtrall[labtr != 24]
yte = (labte == 24).astype(int)
print(Xtrn.shape, Xtes.shape, yte.sum(),len(yte))
```
**Why:** `to_img` reshapes each row to a `(28,28,1)` image in float and divides by 255. `Xtrn = Xtrall[labtr != 24]` **removes letter Y from the training data**; `yte = (labte == 24)` marks the Y images in the test set as the anomaly.

**Why not the alternative:** Not training on Y (the model would learn to rebuild it). Not label 9 as the anomaly (no such letter). Not a scaler: pixel images are simply divided by 255.

### Cell 3: define the autoencoder
```python
#layers
inp = keras.Input(shape=(28,28,1))
x = layers.Conv2D(32,3,strides=2,padding="same",activation="relu")(inp)
x = layers.Conv2D(64,3,strides=2,padding="same",activation="relu")(x)
x = layers.Flatten()(x)
z = layers.Dense(32,activation="relu")(x)
x = layers.Dense(7*7*64,activation="relu")(z)
x = layers.Reshape((7,7,64))(x)
x = layers.Conv2DTranspose(64,3,strides=2,padding="same",activation="relu")(x)
x = layers.Conv2DTranspose(32,3,strides=2,padding="same",activation="relu")(x)
out = layers.Conv2D(1,3,padding="same",activation="sigmoid")(x)
ae = keras.Model(inp,out)
ae.summary()
```
**Why:** Encoder: `Conv2D(32,3,stride 2)` 28 -> 14, `Conv2D(64,3,stride 2)` 14 -> 7, `Flatten` (3,136), **`Dense(32)` bottleneck**; decoder: `Dense(3136)`, `Reshape((7,7,64))`, `Conv2DTranspose` 7 -> 14 -> 28, final `Conv2D(1,3,sigmoid)`. 278,369 parameters.

**Why not the alternative:** Not convolutions only: 7x7x64 = 3,136 numbers in the middle would not compress (AUC dropped from 0.80 to 0.58 in my test). Not a dense autoencoder: images have spatial structure.

### Cell 4: compile and train
```python
#compile
ae.compile(optimizer="adam",loss="mse",metrics=["mae"])
hist = ae.fit(Xtrn,Xtrn,epochs=40,validation_split=0.1,batch_size=128)
```
**Why:** MSE, input = target, 40 epochs, batch 128, `validation_split=0.1` on the normal training images.

**Why not the alternative:** Not more epochs: the validation loss becomes noisy (it jumps at some epochs) and gains are tiny.

### Cell 5: reconstruction error and threshold
```python
#reconstruction error
err_train = np.mean((Xtrn - ae.predict(Xtrn))**2,axis=(1,2,3))
err_test = np.mean((Xtes - ae.predict(Xtes))**2,axis=(1,2,3))
threshold = np.percentile(err_train,95)
pred = (err_test > threshold).astype(int)
print(threshold, pred.sum(),len(pred))
```
**Why:** Error per image with **`axis=(1,2,3)`** (4-D data `(N,28,28,1)`), so `err` has shape `(N,)`. Threshold = 95th percentile of the training errors.

**Why not the alternative:** Not `axis=(1,2)`: it returns `(N,1)`; later the example's `err_test[k]:.4f` fails with `unsupported format string passed to numpy.ndarray.__format__` (your error) and `(yte == 1) & (pred == 1)` selects the wrong image.

### Cell 6: evaluate
```python
#evaluate
print(classification_report(yte,pred,target_names=["normal","anomaly"],digits=3))
print(confusion_matrix(yte,pred))
print(round(roc_auc_score(yte,err_test),4))
```
**Why:** The detector's job is to flag the anomaly class, so the report is read on the **anomaly row** (precision, recall, F1); the confusion matrix `[[TN, FP], [FN, TP]]` shows the counts; **ROC-AUC** scores the error itself without choosing a threshold (0.5 = guessing, 1.0 = perfect).

**Why not the alternative:** Not accuracy: the Y letter is only 4.6 % of the test set, and accuracy 0.62 here hides that the detector flags 40 % of normal images.

### Cell 7: error histogram and training curve
```python
#plot
for k in (0,1):
    plt.hist(err_test[yte==k],50,range=(0,np.percentile(err_test,99)),alpha=0.6,label=["normal","anomaly"][k])
plt.axvline(threshold,color="k",ls="--",label="threshold")
plt.legend()
pd.DataFrame(hist.history).plot();
plt.show()
```
**Why:** The histogram of reconstruction errors (normal against anomaly) with the dashed threshold line is the key plot: the less the two colours overlap, the better the detector. The training curve shows the loss falling and flattening (`validation_split` here is a slice of the normal training data).

**Why not the alternative:** Not only numbers: the overlap in the histogram explains the precision and recall values.

### Cell 8: one example
```python
#one example
i = np.where(yte == 0)[0][0]                       # first normal letter
j = np.where((yte == 1) & (pred == 1))[0][0]       # first Y the model caught
for n, k in enumerate((i, j)):
    plt.subplot(2, 2, n+1); plt.imshow(Xtes[k,:,:,0], cmap="gray"); plt.title(f"input {chr(65+labte[k])}")
    plt.subplot(2, 2, n+3); plt.imshow(ae.predict(Xtes[k:k+1])[0,:,:,0], cmap="gray"); plt.title(f"error {err_test[k]:.4f} -> {'ANOMALY' if pred[k] else 'ok'}")
plt.tight_layout(); plt.show()
```
**Why:** Shows a normal letter and a caught Y as input (top) and reconstruction (bottom) with the error: G is rebuilt well, Y comes out blurry with a much larger error.

**Why not the alternative:** Not only the aggregate scores: one normal and one anomalous sample make the idea visible: small error = rebuilt well, large error = not rebuilt.

## 4. Terminology used in this notebook

| Term | Meaning |
|---|---|
| **Autoencoder** | A network trained to reproduce its input through a narrow middle layer (`fit(X, X)`), so it learns a compressed representation. |
| **Encoder / decoder** | The encoder compresses the input to a small code; the decoder rebuilds the input from the code. |
| **Bottleneck (latent code)** | The narrow middle layer. It must be smaller than the input, otherwise the network just copies. |
| **Reconstruction error** | How far the rebuilt sample is from the original (mean squared difference per sample). Large for anomalies. |
| **Conv2D** | A layer of small filters (for example 3x3) that slide over an image and detect local patterns. |
| **Stride** | How many positions the filter jumps each step; stride 2 halves the size. |
| **Padding** | `valid` = no padding (output shrinks); `same` = zero-pad so the size is kept at stride 1. |
| **Conv1DTranspose / Conv2DTranspose** | Up-sampling convolutions that grow a signal or image back to its original size in the decoder. |
| **Flatten** | Turns a 2-D or 3-D feature map into one long vector so Dense layers can use it. |
| **Sigmoid** | Activation that squashes a number to 0..1 (a probability for two classes, or a scaled value). |
| **Percentile** | The value below which a given percentage of the data lies (95th percentile = larger than 95 % of normal errors). |
| **Threshold** | The error value above which a sample is called an anomaly. |
| **Anomaly** | A sample that does not look like normal data (fraud, abnormal heartbeat, faulty engine, unseen letter). |
| **Precision** | Of everything flagged positive, the fraction that really is positive: TP / (TP + FP). |
| **Recall** | Of all real positives, the fraction found: TP / (TP + FN). |
| **F1 score** | Harmonic mean of precision and recall: 2PR / (P + R). |
| **ROC-AUC** | Probability that a random anomaly gets a higher score than a random normal sample. 0.5 = guessing, 1.0 = perfect. Needs no threshold. |
| **Normalisation (/255)** | Dividing pixels by 255 so inputs are in 0..1: small, similar-sized inputs give stable, faster training. |

## 5. Theory you must be able to explain

**Idea.** Train a conv autoencoder on 24 classes of signs; show it a letter it has never seen (Y). It should rebuild Y worse than the known letters.

**Why the result is weak (AUC 0.83, F1 0.18).** Y shares most of its shape with other letters, so the autoencoder generalises to it; and normal test images have about **twice the reconstruction error of training images** (the test images differ from the training ones), so a threshold taken from training errors flags about 40 % of the normal test images (normal recall 0.605).

**Reading the numbers.** Recall 0.904 (it flags 300 of 332 Y images) but precision 0.100 (2,704 false alarms). AUC 0.83 says the error does carry signal, but a single threshold cannot separate the classes well.

**Error axis for images.** `axis=(1,2,3)`: height, width and channel are all averaged; keep only the sample axis.

**Mean error per letter** (an optional check): the bar for label 24 (Y) is the tallest of the 25, which shows the autoencoder does notice the unseen letter even though one threshold struggles.

## 6. Why we did this, and why not that

| Decision | Why we did it | Why not the alternative |
|---|---|---|
| Hold out label 24 | A clean 'unseen class' anomaly | Not label 9 (does not exist) |
| Conv2D encoder/decoder | Images have spatial structure | A dense autoencoder ignores it |
| `Dense(32)` bottleneck | Forces compression | A pure convolutional middle (3,136 numbers) just copies |
| `axis=(1,2,3)` | 4-D images | `axis=(1,2)` gives an `(N,1)` array and breaks the example |
| 95th percentile from training errors | Standard rule | It under-estimates test errors here; a higher percentile (99th) raises precision to about 0.12 |
| Report AUC and the anomaly row | Accuracy 0.62 hides the problem | Accuracy alone |

## 9. Viva questions with answers

**Q. What is the anomaly here?**

A. The held-out letter Y (label 24): the autoencoder never sees it in training.

**Q. Why is 3F so much weaker than 3E?**

A. Y looks like other letters, and test images produce larger errors than training images, so the errors overlap.

**Q. What do precision 0.10 and recall 0.90 mean?**

A. It flags 300 of 332 Y images but also 2,704 normal images, so only 10 % of alarms are Y.

**Q. What is the error axis and why?**

A. `(1,2,3)`: average over height, width and channel, leaving one error per image.

**Q. Why the Dense(32) bottleneck?**

A. Without it the 7x7x64 middle layer is larger than the input and the network copies.

**Q. How could you improve it?**

A. A higher threshold percentile, a smaller bottleneck, more data or augmentation, or a different anomaly score.

**Q. Why is accuracy 0.62 misleading?**

A. It mixes the huge normal class with the tiny Y class; the anomaly row and AUC show the real behaviour.
