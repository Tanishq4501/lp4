## 1. What the PS asks (in plain words)
Detect anomalies in smart-grid energy consumption data with an LSTM autoencoder: pre-process (fill missing values, normalise, build time windows), train on normal windows, flag windows with a large reconstruction error.

## 2. Dataset
- `energy_consumption.csv`: **5,000 half-hourly readings** from 01-01-2024 with `Timestamp`, `Electricity_Consumed`, `Temperature`, `Humidity`, `Wind_Speed`, `Avg_Past_Consumption` and `Anomaly_Label` (1 = anomaly).
- The rows are already in time order and have no missing values (the fill step is kept for safety).
- Your windows: 10 consecutive readings (5 hours). Normal training windows 2,463; test windows 1,491, of which **436 contain an anomaly**.

## 3. Notebook walkthrough: every cell, and why

### Cell 0: imports

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split

```
**Why:** `tensorflow` first (DLL safety). `MinMaxScaler` scales the features, `classification_report`, `confusion_matrix`, `roc_auc_score` evaluate the detector, `matplotlib` plots.

### Cell 1: dataset
```python
#dataset
layers = tf.keras.layers
keras.utils.set_random_seed(42)
df = pd.read_csv("energy_consumption.csv")
df.head()
```
**Why:** `layers = tf.keras.layers` and `set_random_seed(42)` sit in the dataset cell: a short name for the layers and repeatable training. `pd.read_csv` loads the data and `df.head()` shows the columns (the features already look scaled to 0-1).

### Cell 2: time order and missing values
```python
df["Timestamp"] = pd.to_datetime(df["Timestamp"],format="%d-%m-%Y %H:%M")
df = df.sort_values("Timestamp").reset_index(drop=True)
FEATURES = ["Electricity_Consumed", "Temperature", "Humidity", "Wind_Speed", "Avg_Past_Consumption"]
N_FEATURES = len(FEATURES)
df[FEATURES] = df[FEATURES].interpolate().bfill().ffill()
```
**Why:** `to_datetime(..., format="%d-%m-%Y %H:%M")` turns the text into real dates (day first). Sorting by time makes the rows chronological, and `interpolate().bfill().ffill()` fills any missing values (there are none here). `FEATURES` are the 5 input columns.

**Why not the alternative:** Not sorting the text timestamps (day-first text sorts wrongly) and not dropping rows with gaps (it would break the time sequence).

### Cell 3: split in time order and scale
```python
#split
split = int(len(df) * 0.7)                                                
train_rows, test_rows = df.iloc[:split], df.iloc[split:]
scaler = MinMaxScaler().fit(train_rows.loc[train_rows.Anomaly_Label == 0, FEATURES])
```
**Why:** `split = int(len(df)*0.7)`: the **first 70 % is the training period and the last 30 % the test period**. The `MinMaxScaler` is fitted on the **normal training rows only** (`Anomaly_Label == 0`).

**Why not the alternative:** Not a random split: overlapping windows and time order would leak the future into training. Not fitting the scaler on all rows.

### Cell 4: window (the extra step)
```python
#window <- extra thing
def make_windows(rows):
    data, lab = scaler.transform(rows[FEATURES]), rows["Anomaly_Label"].values
    n = len(data) - 10 + 1
    W = np.array([data[i:i + 10] for i in range(n)], dtype="float32")            # (n, 10, 5)
    y = np.array([lab[i:i + 10].max() for i in range(n)])                        # window is anomalous if ANY step is
    return W, y
Wtrall, ytr = make_windows(train_rows)
Xtes, yte = make_windows(test_rows)
Xtrn = Wtrall[ytr == 0]   

print(Xtrn.shape, Xtes.shape, yte.sum(),len(yte))
```
**Why:** `make_windows` slides a window of 10 consecutive rows over the data to create samples of shape `(10, 5)`: `data[i:i+10]`. A window is **anomalous if any of its 10 steps is** (`lab[i:i+10].max()`). `Xtrn` keeps only the normal training windows, so the model learns normal behaviour. Result: `(2463, 10, 5) (1491, 10, 5) 436 1491`.

**Why not the alternative:** Not one row per sample: an LSTM needs a sequence. Not the label of the last step only: an anomaly anywhere in the window should flag it. Not training on anomalous windows.

### Cell 5: define the LSTM autoencoder
```python
#layers
inp = keras.Input(shape=(10,5))
x = layers.LSTM(32)(inp)
x = layers.RepeatVector(10)(x)
x = layers.LSTM(32,return_sequences=True)(x)
out = layers.TimeDistributed(layers.Dense(5))(x)
ae = keras.Model(inp,out)
ae.summary()
```
**Why:** `LSTM(32)` reads the whole window and outputs one vector (the bottleneck); **`RepeatVector(10)`** copies it once per time step; `LSTM(32, return_sequences=True)` unrolls it back into a sequence; **`TimeDistributed(Dense(5))`** produces the 5 features at every step. 13,349 parameters.

**Why not the alternative:** Not a Dense autoencoder: it would treat each time step as independent and ignore the time order. Not a bigger LSTM: the data is small.

### Cell 6: compile and train with early stopping
```python
ae.compile(optimizer="adam",loss="mse",metrics=["mae"])
stop = keras.callbacks.EarlyStopping(monitor="val_loss",patience=4,restore_best_weights=True)
hist = ae.fit(Xtrn,Xtrn,epochs=30,batch_size=64,validation_split=0.1,callbacks=[stop])
```
**Why:** MSE loss, input = target. `EarlyStopping(monitor="val_loss", patience=4, restore_best_weights=True)` stops when the validation loss stops improving and keeps the best weights. 30 epochs maximum, batch 64, `validation_split=0.1`.

**Why not the alternative:** Not a fixed long run: it wastes time and can over-fit.

### Cell 7: reconstruction error and threshold
```python
#reconstruction error
err_train = np.mean((Xtrn - ae.predict(Xtrn))**2,axis=(1,2))
err_test = np.mean((Xtes - ae.predict(Xtes))**2,axis=(1,2))
threshold = np.percentile(err_train,95)
pred = (err_test > threshold).astype(int)
print(threshold, pred.sum(),len(pred))
```
**Why:** Error per window with `axis=(1,2)` (3-D data `(N,10,5)`: average over time and features). Threshold = **95th percentile of the normal training errors**.

**Why not the alternative:** Not `axis=1` (that leaves a feature axis). Not mean + 3 std: the errors are skewed.

### Cell 8: evaluate
```python
#evaluate
print(classification_report(yte,pred,target_names=["normal","anomaly"],digits=3))
print(confusion_matrix(yte,pred))
print(round(roc_auc_score(yte,err_test),4))
```
**Why:** Precision, recall and F1 of the anomaly row, the confusion matrix and ROC-AUC. The result is weak because the anomalies are random spikes.

**Why not the alternative:** Not accuracy: 0.728 looks acceptable but hides that only 23 % of anomalous windows are found.

## 4. Terminology used in this notebook

| Term | Meaning |
|---|---|
| **Window** | W consecutive rows treated as one sample, giving data of shape (samples, W, features). |
| **LSTM** | A recurrent layer with a memory cell and gates (input, forget, output); it learns dependencies over time and avoids the vanishing gradient of plain RNNs. |
| **RepeatVector** | Copies the encoded vector once per time step so the decoder LSTM has a sequence to unroll. |
| **TimeDistributed** | Applies the same Dense layer to every time step of a sequence. |
| **EarlyStopping** | Stops training when the validation loss stops improving (and, with `restore_best_weights`, goes back to the best epoch). |
| **Autoencoder** | A network trained to reproduce its input through a narrow middle layer (`fit(X, X)`), so it learns a compressed representation. |
| **Bottleneck (latent code)** | The narrow middle layer. It must be smaller than the input, otherwise the network just copies. |
| **Reconstruction error** | How far the rebuilt sample is from the original (mean squared difference per sample). Large for anomalies. |
| **MSE** | Mean squared error: the average of `(input - reconstruction)^2`. The autoencoder loss. |
| **Threshold** | The error value above which a sample is called an anomaly. |
| **Percentile** | The value below which a given percentage of the data lies (95th percentile = larger than 95 % of normal errors). |
| **Anomaly** | A sample that does not look like normal data (fraud, abnormal heartbeat, faulty engine, unseen letter). |
| **MinMaxScaler** | Scales each feature to 0..1 using the training minimum and maximum. |
| **Data leakage** | Information from test data (or from the answer) leaking into training, for example fitting a scaler on all data or keeping RUL as an input. |
| **Precision** | Of everything flagged positive, the fraction that really is positive: TP / (TP + FP). |
| **Recall** | Of all real positives, the fraction found: TP / (TP + FN). |
| **F1 score** | Harmonic mean of precision and recall: 2PR / (P + R). |
| **Confusion matrix** | Table of true class (rows) against predicted class (columns). The diagonal is correct. |
| **ROC-AUC** | Probability that a random anomaly gets a higher score than a random normal sample. 0.5 = guessing, 1.0 = perfect. Needs no threshold. |
| **Time-ordered split** | Train on the earlier period and test on the later period so no future information reaches training. |

## 5. Theory you must be able to explain

**Why an LSTM.** Energy readings depend on the previous readings; an LSTM keeps a memory cell and gates (input, forget, output) that learn what to remember, and avoids the vanishing gradient of a simple RNN. A Dense autoencoder would treat each time step independently.

**LSTM autoencoder.** The encoder LSTM compresses a window to one vector; `RepeatVector` feeds that vector to the decoder LSTM at every step; `TimeDistributed(Dense)` outputs the features per step. Training on normal windows only makes anomalous windows reconstruct badly.

**Windowing.** Sliding a window of W rows turns one long series into many samples of shape `(W, features)`: `np.array([a[i:i+W] for i in range(len(a)-W+1)])`.

**Why the result is weak (AUC 0.69).** The anomalies are random spikes in a noisy series, so there is no stable pattern for the autoencoder to miss. Precision 0.59 and recall 0.23 mean it finds few of them. Do not think your code is wrong: say so in the viva.

**Early stopping.** Monitoring the validation loss and restoring the best weights prevents over-fitting and saves time.

## 6. Why we did this, and why not that

| Decision | Why we did it | Why not the alternative |
|---|---|---|
| Time-ordered 70/30 split | Avoids leaking the future into training | A random split mixes overlapping windows |
| Window of 10, label = any step anomalous | A short sequence for the LSTM; an anomaly anywhere counts | Single rows give no sequence |
| Scaler fitted on normal training rows | No leakage; features on the same scale | Fitting on all data |
| LSTM autoencoder | Captures time dependence | Dense autoencoder ignores time order |
| Early stopping | Stops when validation loss stops improving | Fixed epochs may over-fit |
| 95th percentile threshold | Adjustable for skewed errors | mean + 3 std assumes a bell shape |
| `axis=(1,2)` | 3-D data | `axis=1` leaves a feature axis |
