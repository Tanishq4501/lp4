## 1. What the PS asks (in plain words)
Detect anomalies with a **convolutional** autoencoder. The original PS uses MVTec images; Ma'am allowed the ECG data, so the same idea is built with 1-D convolutions on the heartbeat signal.

## 2. Dataset
- Same `ecg.csv` as 3E: 4,998 beats of 140 values; label 1 = normal, 0 = abnormal; 2,335 normal training beats; 1,000 test beats (416 abnormal).
- **The data is numbers (a signal), not images**: each beat is a 1-D time series, so the layers are `Conv1D`. (The original MVTec version would use `Conv2D`.)

## 3. Notebook walkthrough: every cell, and why

### Cell 0: imports
```python
import tensorflow as tf
from tensorflow import keras
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler, MinMaxScaler
from sklearn.metrics import classification_report, confusion_matrix, roc_auc_score
```
**Why:** `tensorflow` first (DLL safety on this machine). `train_test_split` splits the data, `StandardScaler` / `MinMaxScaler` scale features, `classification_report`, `confusion_matrix` and `roc_auc_score` evaluate the detector (never plain accuracy), `matplotlib` draws the histogram and curves.

### Cell 1: dataset
```python
#dataset
keras.utils.set_random_seed(42)
layers = tf.keras.layers
df = pd.read_csv("ecg.csv",header=None)
df.head()
```
**Why:** Same data loading as 3E (`header=None`).

### Cell 2: split and scale
```python
#train n split
X = df.iloc[:,:-1].values.astype("float32")
y = (df.iloc[:,-1].values == 0).astype(int)
Xtr,Xte,ytr,yte = train_test_split(X,y,test_size=0.2,stratify=y,random_state=42)
scaler = MinMaxScaler().fit(Xtr[ytr == 0])
Xtrn = scaler.transform(Xtr[ytr == 0])
Xtes = scaler.transform(Xte)
print(Xtrn.shape, Xtes.shape, yte.sum(), len(yte))
```
**Why:** Same as 3E: signal = all columns except the last, `y = (last column == 0)`, stratified 80/20, `MinMaxScaler` fitted on normal training beats.

**Why not the alternative:** Same traps as 3E: not `iloc[:,:-1] == 0` for `y`, not fitting the scaler on all data.

### Cell 3: add a channel axis
```python
Xtrn = Xtrn[..., None]
Xtes = Xtes[..., None]
```
**Why:** `[..., None]` turns `(N, 140)` into `(N, 140, 1)`: Conv1D expects `(samples, time steps, channels)`, and an ECG has one channel.

**Why not the alternative:** Not skipping it (Conv1D would reject 2-D data). **Run this cell once and only after the split cell**: re-running the split cell resets the data to 2-D and causes a shape error (your error), and running it twice makes a 4-D array. Safer: put `[..., None]` inside the split cell.

### Cell 4: define the autoencoder
```python
#layers
inp = keras.Input(shape=(140,1))
x = layers.Conv1D(32,5,strides=2,padding="same",activation="relu")(inp)
x = layers.Conv1D(16,5,strides=2,padding="same",activation="relu")(x)
x = layers.Flatten()(x)
z = layers.Dense(16,activation="relu")(x)
x = layers.Dense(35 * 16,activation="relu")(z)
x = layers.Reshape((35,16))(x)
x = layers.Conv1DTranspose(16,5,strides=2,padding="same",activation="relu")(x)
x = layers.Conv1DTranspose(32,5,strides=2,padding="same",activation="relu")(x)
out = layers.Conv1D(1,5,padding="same",activation="sigmoid")(x)
ae = keras.Model(inp,out)
ae.summary()
```
**Why:** Encoder: `Conv1D(32,5,stride 2)` 140 -> 70, `Conv1D(16,5,stride 2)` 70 -> 35, `Flatten` (560), **`Dense(16)` bottleneck**; decoder: `Dense(560)`, `Reshape((35,16))`, `Conv1DTranspose` 35 -> 70 -> 140, final `Conv1D(1,5,sigmoid)`. 25,313 parameters.

**Why not the alternative:** Not convolutions alone without the Flatten/Dense bottleneck: 35 x 16 = 560 numbers is bigger than the 140 inputs, so the network can copy (in my tests AUC fell from 0.98 to 0.93). Not `Conv2D`: this is a 1-D signal.

### Cell 5: compile and train
```python
#compile
ae.compile(optimizer="adam",loss="mse",metrics=["mae"])
hist = ae.fit(Xtrn,Xtrn,epochs=40,validation_split=0.1,batch_size=64)
```
**Why:** MSE, input = target, 40 epochs, batch 64, `validation_split=0.1`.

**Why not the alternative:** Not more epochs: the loss has flattened.

### Cell 6: reconstruction error and threshold
```python
#reconstruction error
err_train = np.mean((Xtrn - ae.predict(Xtrn))**2,axis=(1,2))
err_test = np.mean((Xtes - ae.predict(Xtes))**2,axis=(1,2))
threshold = np.percentile(err_train,95)
pred = (err_test > threshold).astype(int)
print(threshold, pred.sum(),len(pred))
```
**Why:** Error per beat with `axis=(1,2)`: the data is 3-D `(N,140,1)`, so average over every axis except the first. Threshold = 95th percentile of normal training errors.

**Why not the alternative:** Not `axis=1` on 3-D data: it returns shape `(N, 1)` and breaks the later cells. Not the raw array: use the scaled `Xtes`.

### Cell 7: evaluate
```python
#evaluate
print(classification_report(yte,pred,target_names=["normal","anomaly"],digits=3))
print(confusion_matrix(yte,pred))
print(round(roc_auc_score(yte,err_test),4))
```
**Why:** The detector's job is to flag the anomaly class, so the report is read on the **anomaly row** (precision, recall, F1); the confusion matrix `[[TN, FP], [FN, TP]]` shows the counts; **ROC-AUC** scores the error itself without choosing a threshold (0.5 = guessing, 1.0 = perfect).

**Why not the alternative:** Not accuracy: the classes are fairly balanced here, but the anomaly row tells how well abnormal beats are found.

### Cell 8: error histogram and training curve
```python
#plot
for k in (0,1):
    plt.hist(err_test[yte==k],50,range=(0,np.percentile(err_test,99)),alpha=0.6,label=["normal","anomaly"][k])
plt.axvline(threshold,color="k",ls="--",label="threshold")
plt.legend()
pd.DataFrame(hist.history).plot();
plt.show()
```
**Why:** The histogram of reconstruction errors (normal against anomaly) with the dashed threshold line is the key plot: the less the two colours overlap, the better the detector. The training curve shows the loss falling and flattening (`validation_split` here is a slice of the normal training data).

**Why not the alternative:** Not only numbers: the overlap in the histogram explains the precision and recall values.

### Cell 9: one example
```python
#one example
i = np.where(yte == 0)[0][0]                       # first normal transaction
j = np.where((yte == 1) & (pred == 1))[0][0]       # first fraud the model caught
print(f"normal: error {err_test[i]:.3f} -> {'ANOMALY' if pred[i] else 'ok'}")
print(f"fraud : error {err_test[j]:.3f} -> {'ANOMALY' if pred[j] else 'ok'} | threshold {threshold:.3f}")

```
**Why:** Prints one normal and one caught abnormal beat (normal 0.001 -> ok; abnormal 0.007 -> ANOMALY; threshold 0.003).

**Why not the alternative:** Not only the aggregate scores: one normal and one anomalous sample make the idea visible: small error = rebuilt well, large error = not rebuilt.

## 4. Terminology used in this notebook

| Term | Meaning |
|---|---|
| **Autoencoder** | A network trained to reproduce its input through a narrow middle layer (`fit(X, X)`), so it learns a compressed representation. |
| **Encoder / decoder** | The encoder compresses the input to a small code; the decoder rebuilds the input from the code. |
| **Bottleneck (latent code)** | The narrow middle layer. It must be smaller than the input, otherwise the network just copies. |
| **Reconstruction error** | How far the rebuilt sample is from the original (mean squared difference per sample). Large for anomalies. |
| **Conv1D** | The same idea for a 1-D signal: a filter slides along time. |
| **Filter / kernel** | The small weight window of a convolution layer. `Conv2D(32, 3)` learns 32 filters of size 3x3. |
| **Stride** | How many positions the filter jumps each step; stride 2 halves the size. |
| **Padding** | `valid` = no padding (output shrinks); `same` = zero-pad so the size is kept at stride 1. |
| **Conv1DTranspose / Conv2DTranspose** | Up-sampling convolutions that grow a signal or image back to its original size in the decoder. |
| **Flatten** | Turns a 2-D or 3-D feature map into one long vector so Dense layers can use it. |
| **Sigmoid** | Activation that squashes a number to 0..1 (a probability for two classes, or a scaled value). |
| **MinMaxScaler** | Scales each feature to 0..1 using the training minimum and maximum. |
| **Percentile** | The value below which a given percentage of the data lies (95th percentile = larger than 95 % of normal errors). |
| **Threshold** | The error value above which a sample is called an anomaly. |
| **Precision** | Of everything flagged positive, the fraction that really is positive: TP / (TP + FP). |
| **Recall** | Of all real positives, the fraction found: TP / (TP + FN). |
| **F1 score** | Harmonic mean of precision and recall: 2PR / (P + R). |
| **ROC-AUC** | Probability that a random anomaly gets a higher score than a random normal sample. 0.5 = guessing, 1.0 = perfect. Needs no threshold. |
| **Channel** | The last axis of the data; an ECG has 1 channel, a colour image has 3. |

## 5. Theory you must be able to explain

**Why Conv1D for ECG.** A heartbeat is a 1-D signal. A shared 5-sample filter learns local waveform shapes (the QRS spike, the ST segment) wherever they occur, with far fewer weights than a dense layer on 140 points.

**Shapes.** 140 -> (stride 2) 70 -> 35 -> Flatten 560 -> 16 -> 560 -> reshape (35,16) -> up-sample 70 -> 140. Conv1DTranspose with stride 2 doubles the length.

**The bottleneck rule (confirmed by testing).** A purely convolutional version with 35 x 16 values in the middle is not a bottleneck and gives a lower AUC; the `Flatten -> Dense(16)` squeeze fixes it.

**Error axis rule.** Average over every axis except the first: `(N,30)` -> `axis=1`, `(N,140,1)` -> `axis=(1,2)`, `(N,28,28,1)` -> `axis=(1,2,3)`.

**Result vs 3E.** Both reach AUC about 0.98-0.99 and a similar F1 (0.967 against 0.965). The conv version is not much better on this data; the point of 3B is to show convolution on a signal.

## 6. Why we did this, and why not that

| Decision | Why we did it | Why not the alternative |
|---|---|---|
| Conv1D (not Dense) | Shared filters learn local waveform shapes | Dense layers ignore locality (3E) |
| Add a channel axis | Conv1D needs `(N, steps, channels)` | 2-D data raises a shape error |
| `Flatten -> Dense(16)` bottleneck | Forces real compression | Convolutions alone leave 560 numbers in the middle, bigger than the input |
| Sigmoid output, MinMax data | Both in 0..1 | A linear output would not be bounded |
| `axis=(1,2)` | 3-D data | `axis=1` returns an `(N,1)` array |
| 95th percentile | Same rule as 3E | mean + 3 std is for 3A |

## 9. Viva questions with answers

**Q. Why Conv1D and not Conv2D?**

A. The data is a 1-D signal (140 values per beat); the filter slides along time.

**Q. Why add `[..., None]`?**

A. Conv1D needs a channel axis: `(N,140)` becomes `(N,140,1)`.

**Q. Why the Flatten -> Dense(16) bottleneck?**

A. Without it the middle layer (35x16 = 560) is larger than the input and the network can copy.

**Q. What does Conv1DTranspose do?**

A. Up-samples the signal back to its original length in the decoder.

**Q. Why `axis=(1,2)` for the error?**

A. The data is 3-D; average over every axis except the sample axis.

**Q. Compare with 3E.**

A. Both about AUC 0.98-0.99; 3B uses convolutions that exploit the signal's local shapes.

**Q. What would the original (MVTec) version change?**

A. Conv2D layers on images, error `axis=(1,2,3)`.
