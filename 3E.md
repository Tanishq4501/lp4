## 1. What the PS asks (in plain words)
Detect abnormal heartbeats with a dense autoencoder (Ma'am allowed the ECG data in place of the original NSL-KDD): train on normal beats, threshold the reconstruction error, evaluate.

## 2. Dataset
- `ecg.csv`: 4,998 heartbeats, each **140 signal values** and a label in the **last column**, no header.
- In this file **label 1 = normal** (2,919 beats) and **label 0 = abnormal** (2,079 beats), so the anomaly is `label == 0`.
- Your split: 80/20 stratified, 2,335 normal beats for training; test set 1,000 beats (416 abnormal, 584 normal).

## 3. Notebook walkthrough: every cell, and why

### Cell 0: imports
```python
import tensorflow as tf
from tensorflow import keras
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler, MinMaxScaler
from sklearn.metrics import classification_report, roc_auc_score, confusion_matrix
```
**Why:** `tensorflow` first (DLL safety on this machine). `train_test_split` splits the data, `StandardScaler` / `MinMaxScaler` scale features, `classification_report`, `confusion_matrix` and `roc_auc_score` evaluate the detector (never plain accuracy), `matplotlib` draws the histogram and curves.

### Cell 1: dataset
```python
#dataset
layers = tf.keras.layers
df = pd.read_csv("ecg.csv",header=None)
keras.utils.set_random_seed(42)
df.head()
```
**Why:** `header=None` because the file has no header row; `df.head()` shows 141 columns (0-139 signal, 140 label). `set_random_seed(42)` makes runs repeatable.

### Cell 2: split and scale
```python
#split n scale
X = df.iloc[:,:-1].values.astype("float32")
y = (df.iloc[:,-1].values == 0).astype(int)
Xtr,Xte,ytr,yte = train_test_split(X,y,test_size=0.2,stratify=y,random_state=42)
scaler = MinMaxScaler().fit(Xtr[ytr == 0])
Xtrn = scaler.transform(Xtr[ytr == 0])
Xtes = scaler.transform(Xte)
print(Xtrn.shape, yte.sum(),len(yte))
```
**Why:** `X = df.iloc[:,:-1]` (all columns **except** the last) are the 140 signal values; `y = (df.iloc[:,-1] == 0)` uses **only the last column** and marks `label 0` as the anomaly. Stratified 80/20 split. `MinMaxScaler` is fitted on **normal training beats only** and scales to 0..1, matching the sigmoid output.

**Why not the alternative:** Not `df.iloc[:,:-1] == 0` for `y` (that compares all 140 signal columns and creates a matrix: your original error). Not `label == 1` as the anomaly: in this file 1 is normal. Not fitting the scaler on all beats (leakage).

### Cell 3: define the autoencoder
```python
#layers
inp = keras.Input(shape=(140,))
x = layers.Dense(64,activation="relu")(inp)
x = layers.Dense(32,activation="relu")(x)
z = layers.Dense(16,activation="relu")(x)
x = layers.Dense(32,activation="relu")(z)
x = layers.Dense(64,activation="relu")(x)
out = layers.Dense(140,activation="sigmoid")(x)
ae = keras.Model(inp,out)
ae.summary()
```
**Why:** Dense 140 -> 64 -> 32 -> **16 (bottleneck)** -> 32 -> 64 -> 140. The output is `sigmoid` because the data is scaled to 0..1. 23,388 parameters.

**Why not the alternative:** Not a linear output (3A): the data is 0..1, sigmoid fits it. Not a conv layer: that is 3B, the same data with Conv1D.

### Cell 4: compile and train
```python
#compile
ae.compile(optimizer="adam",loss="mse",metrics=["mae"])
hist = ae.fit(Xtrn,Xtrn,batch_size=64,validation_split=0.1,epochs=40)
```
**Why:** MSE loss, input = target (`fit(Xtrn, Xtrn)`), 40 epochs, batch 64, `validation_split=0.1` on normal beats.

**Why not the alternative:** Not training on abnormal beats. Not more epochs: the loss has flattened by epoch 40.

### Cell 5: reconstruction error and threshold
```python
#reconstruction error
err_train = np.mean((Xtrn - ae.predict(Xtrn))**2,axis=1)
err_test = np.mean((Xtes - ae.predict(Xtes))**2,axis=1)
threshold = np.percentile(err_train,95)
pred = (err_test > threshold).astype(int)
print(threshold, pred.sum(),len(pred))
```
**Why:** Error per beat with `axis=1` (2-D data). `err_test` must use the **scaled** test array `Xtes`. Threshold = **95th percentile of the normal training errors**: 5 % of normal beats will be false alarms by construction, which is acceptable because the abnormal beats are clearly different.

**Why not the alternative:** Not the raw `Xte`: the model was trained on scaled data, so raw values make every beat look abnormal (all 1,000 flagged; this was your bug). Not mean + 3 std here: the percentile gave a better balance for ECG.

### Cell 6: evaluate
```python
#evaluate
print(classification_report(yte,pred,target_names=["normal","anomaly"],digits=3))
print(confusion_matrix(yte,pred))
print(round(roc_auc_score(yte,err_test),4))
```
**Why:** The detector's job is to flag the anomaly class, so the report is read on the **anomaly row** (precision, recall, F1); the confusion matrix `[[TN, FP], [FN, TP]]` shows the counts; **ROC-AUC** scores the error itself without choosing a threshold (0.5 = guessing, 1.0 = perfect).

**Why not the alternative:** Not accuracy: the classes are fairly balanced here (42 % abnormal), but precision, recall and AUC still show how each class is treated.

### Cell 7: error histogram and training curve
```python
#plot
for k in (0,1):
    plt.hist(err_test[yte==k],50,range=(0,np.percentile(err_test,99)),alpha=0.6,label=["normal","anomaly"][k])
plt.axvline(threshold,color="k",ls="--",label="threshold")
plt.legend()
pd.DataFrame(hist.history).plot();
plt.show()
```
**Why:** The histogram of reconstruction errors (normal against anomaly) with the dashed threshold line is the key plot: the less the two colours overlap, the better the detector. The training curve shows the loss falling and flattening (`validation_split` here is a slice of the normal training data).

**Why not the alternative:** Not only numbers: the overlap in the histogram explains the precision and recall values.

### Cell 8: one example
```python
#one example
i = np.where(yte == 0)[0][0]                       # first normal transaction
```

**Why:** Prints the error of one normal and one caught abnormal beat (normal 0.001 -> ok; abnormal 0.013 -> ANOMALY; threshold 0.004).

**Why not the alternative:** Not only the aggregate scores: one normal and one anomalous sample make the idea visible: small error = rebuilt well, large error = not rebuilt.

## 4. Terminology used in this notebook

| Term | Meaning |
|---|---|
| **Autoencoder** | A network trained to reproduce its input through a narrow middle layer (`fit(X, X)`), so it learns a compressed representation. |
| **Encoder / decoder** | The encoder compresses the input to a small code; the decoder rebuilds the input from the code. |
| **Bottleneck (latent code)** | The narrow middle layer. It must be smaller than the input, otherwise the network just copies. |
| **Reconstruction error** | How far the rebuilt sample is from the original (mean squared difference per sample). Large for anomalies. |
| **MSE** | Mean squared error: the average of `(input - reconstruction)^2`. The autoencoder loss. |
| **Threshold** | The error value above which a sample is called an anomaly. |
| **Percentile** | The value below which a given percentage of the data lies (95th percentile = larger than 95 % of normal errors). |
| **Anomaly** | A sample that does not look like normal data (fraud, abnormal heartbeat, faulty engine, unseen letter). |
| **MinMaxScaler** | Scales each feature to 0..1 using the training minimum and maximum. |
| **Data leakage** | Information from test data (or from the answer) leaking into training, for example fitting a scaler on all data or keeping RUL as an input. |
| **Sigmoid** | Activation that squashes a number to 0..1 (a probability for two classes, or a scaled value). |
| **ReLU** | `max(0, x)`. Cheap hidden-layer activation that does not saturate for positive values. |
| **Precision** | Of everything flagged positive, the fraction that really is positive: TP / (TP + FP). |
| **Recall** | Of all real positives, the fraction found: TP / (TP + FN). |
| **F1 score** | Harmonic mean of precision and recall: 2PR / (P + R). |
| **Confusion matrix** | Table of true class (rows) against predicted class (columns). The diagonal is correct. |
| **ROC-AUC** | Probability that a random anomaly gets a higher score than a random normal sample. 0.5 = guessing, 1.0 = perfect. Needs no threshold. |

## 5. Theory you must be able to explain

**Same idea as 3A, different data.** Train on normal heartbeats, flag beats whose reconstruction error is above the threshold.

**Scaling and the output layer must match.** MinMax gives 0..1, so the last layer is sigmoid. Evaluate on the scaled array: the scaler is part of the model's input contract.

**Why it works so well (AUC 0.99).** Abnormal heartbeats have a clearly different waveform, so the autoencoder (trained only on normal shapes) rebuilds them badly, and the error histograms hardly overlap.

**Threshold = 95th percentile.** By construction about 5 % of normal beats are above it (your normal recall 0.954 matches this); raising it to the 99th percentile would trade fewer false alarms for more missed beats.

## 6. Why we did this, and why not that

| Decision | Why we did it | Why not the alternative |
|---|---|---|
| `header=None` | The file has no header row | Default `read_csv` would treat the first beat as column names |
| `y` from the last column | The label is column 140 | `iloc[:,:-1]` is the signal, not the label |
| Anomaly = label 0 | 1 is normal in this file | Assuming 1 = anomaly reverses everything |
| MinMaxScaler + sigmoid | Matching 0..1 range | StandardScaler data can be negative, which a sigmoid output cannot rebuild |
| 95th percentile threshold | Adjustable and robust to skewed errors | mean + 3 std assumes a bell-shaped error distribution |
| Evaluate on `Xtes` | Same preprocessing as training | Raw `Xte` flags every beat |

## 9. Viva questions with answers

**Q. Why `y = iloc[:, -1] == 0`?**

A. The label is the last column and label 0 is the abnormal class in this file.

**Q. Why sigmoid at the output?**

A. The data is scaled to 0..1 by MinMaxScaler.

**Q. Why is evaluating on the raw array wrong?**

A. The model was trained on scaled data, so raw values give huge errors and every beat is flagged.

**Q. How was the threshold chosen and what does it imply?**

A. 95th percentile of normal training errors, so about 5 % of normal beats are false alarms.

**Q. Why is the AUC so high here?**

A. Abnormal waveforms differ clearly from normal ones, so errors hardly overlap.

**Q. What is the bottleneck here and why?**

A. 16 units, smaller than 140 inputs, so the network must compress.

**Q. How is 3E different from 3A?**

A. 3A uses standardised tabular data with a linear output and mean + 3 std; 3E uses 0..1 scaled beats with a sigmoid output and a percentile.
